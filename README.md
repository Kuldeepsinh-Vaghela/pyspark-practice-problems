# 🚀 StrataScratch PySpark Solutions

Welcome to my **StrataScratch PySpark Solutions** repository!  
This repo showcases my hands-on solutions to real-world SQL/data engineering problems using **Apache PySpark**. Each problem is solved with a clear and efficient approach, and includes a detailed breakdown and code snippet in its own markdown file.

📌 Ideal for:
- Data Engineering Interviews
- PySpark Practice
- Big Data Analytics
- SQL-to-Spark translation reference

---


> Each solution contains:  
> - Problem link  
> - Approach explanation  
> - Clean PySpark code  
> - Optional sample output

---

## 🔧 Tech Stack

- **Apache PySpark**: Distributed processing of large datasets
- **StrataScratch**: Real interview-style SQL challenges
- **Markdown**: For documenting solutions clearly
- **Pandas**: Used only to display final result from Spark DataFrame

---

## 🧠 Why PySpark?

Most data problems are solved using SQL, but companies at scale use **Spark** for distributed computing. This repo helps bridge the gap between SQL logic and PySpark syntax, making it a great resource for:
- Practicing big data problem-solving
- Preparing for data engineering interviews
- Translating SQL logic into scalable Spark workflows
